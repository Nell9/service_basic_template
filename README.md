## 🛠 Стек и инструменты

- **Менеджер зависимостей:** [Poetry](https://python-poetry.org)
- **Качество кода:** 
  - `Ruff` — быстрый линтер и форматтер.
  - `Black` — строгий стандарт форматирования.
  - `Pre-commit` — автоматическая проверка кода перед коммитом.
- **Конфигурация:** `environs` для работы с переменными окружения.
